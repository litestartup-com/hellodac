DAC — Dispatched Agent Cluster

One Manager. A Fleet of Agents.

An MIT open-source control plane for managing and exposing fleets of containerized agent nodes (currently built on DeepSeek Harness) across multiple servers, with unified conversation and API access.

GitHub Install 中文文档

Quick start

# Linux server (containers, recommended)
curl -fsSL https://raw.githubusercontent.com/litestartup-com/hellodac/v1.0.0/install.sh -o install.sh && bash install.sh

# Windows (bare metal)
irm https://raw.githubusercontent.com/litestartup-com/hellodac/v1.0.0/install.ps1 -OutFile install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1

What it gives you

Fleet topology

One manager, machines joined by a node agent, nodes as container workers or host processes — with a live topology view and heartbeat edges.

Unified conversation

Talk to every node from one place: streaming, tool cards, approvals, per-session model and access mode.

API access

Every node is reachable through one gateway prefix, so third-party clients get the same agents the UI has.

Operations built in

Audit log, cost and budgets, encrypted backups with restore drill, self-update with automatic rollback.

Bilingual UI

English by default, Chinese one click away; adding a language is one JSON file.

Safe by default

Loopback-only node ports, approval cards for dangerous operations, agent tokens that rotate with a grace window.

Status

v1.0.0 — the first public release. The container one-liner and the bare-metal path are both exercised by the project's own smoke tests before every release.
