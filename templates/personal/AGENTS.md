# Personal assistant workspace

This is your workspace. You read and write files here; manager renders the data under `board/` into the dashboard.

> Topology and boundaries are in this workspace's `fleet.md` (generated by manager): the node list, the key address variable (`$MANAGER_URL`) and the cross-node boundary -- read and write this directory only, and cross nodes always by dispatching through manager.

## Iron rules

1. **The files are the only source of truth.** Never answer from memory; read the files first.
2. **Write the document first, then update the dashboard.** `board/*.json` is a summary view of the documents, not a raw record. Raw records go into the matching markdown; the dashboard holds conclusions and numbers only.
3. **When unsure, ask -- never make it up.** If the numbers do not add up, leaving the field empty and saying so beats a plausible-looking value.
4. **Never delete history.** Records are only appended or corrected, never wiped out wholesale.

## How to update the dashboard

Each `.json` under `board/` is one page of the dashboard, and the file describes itself:

```json
{
  "label": "Overview",
  "order": 1,
  "blocks": [ ... ]
}
```

- A new page = a new `.json`; no other file needs changing.
- `board/meta.json` holds only the title and `asOf`. **Every change to the dashboard must set `asOf` to today.**

### Available blocks (only these -- anything else will not render)

| type | Purpose | Required fields |
|---|---|---|
| `kpi` | Big numbers at the top | `items[].label`, `items[].value` |
| `metrics` | Current value vs target | `items[].name`, `items[].value` |
| `list` | Plans, to-dos, notes to self | `items[].text` |
| `table` | Multi-column detail | `columns`, `rows` |
| `progress` | Budget or completion bars | `items[].label`, `items[].value`, `items[].max` |
| `bars` | Bar trend (may be negative) | `items[].label`, `items[].value` |
| `pie` | Share breakdown | `items[].label`, `items[].value` |
| `checklist` | Daily habits to tick off | `items[].text`, `items[].done` |
| `quote` | A line a day (rotates by date) | `items[].text` |
| `groups` | Grouped list | `groups[].label`, `groups[].items` |
| `note` | A paragraph of explanation | `text` |

Optional fields: `title` (the card title) and `tone` (`good` / `warn` / `bad` / `info` / `muted`, used for colouring).

### Watch out

- Numeric fields must be **numbers**, not strings. `"value": 71.5`, not `"value": "71.5"`.
- For `kpi` and `metrics`, `value` is **display text**, so it may carry a unit, for example `"71.5kg"`.
- A malformed card does not bring the whole page down, but that card turns into an obvious error block and shows up in the problem list at the top of the dashboard. Fix it when you see it.
