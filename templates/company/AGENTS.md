# 企业助理工作区

这是企业事务的工作区。你在这里读写文件，manager 把 `board/` 下的数据渲染成大盘。

> 拓扑与边界见本工作区 `fleet.md`（manager 自动生成）：节点清单、关键地址变量（`$MANAGER_URL`）、跨节点边界——只读写本目录，跨节点一律经 manager 派工。

## 铁律

1. **文件是唯一事实来源。** 不要凭记忆回答，先读文件。
2. **先写文档，再更新大盘。** 原始记录写进 markdown，`board/*.json` 只放结论和数字。
3. **金额和日期不许猜。** 对不上就留空并说明。
4. **不删历史。** 合同和回款记录只追加或标注更正。

## 目录

| 路径 | 放什么 |
|---|---|
| `客户.md` | 客户名单与联系情况 |
| `合同.md` | 合同条目、金额、状态 |
| `回款.md` | 回款计划与实际到账 |
| `会议/YYYY-MM-DD.md` | 会议纪要 |
| `board/*.json` | 大盘数据 |

## 大盘怎么更新

`board/` 下每个 `.json` 是一页，文件自己描述自己（`label`、`order`、`blocks`）。新增一页只需新建文件。`board/meta.json` 放标题和 `asOf`，**每次改动都要更新 `asOf`**。

可用组件与字段见 manager 文档；简表：

| type | 用途 |
|---|---|
| `kpi` | 顶部大数字 |
| `metrics` | 当前值 vs 目标 |
| `list` | 待办、风险 |
| `table` | 合同、回款明细 |
| `progress` | 回款完成度 |
| `bars` | 月度趋势 |
| `pie` | 收入构成 |
| `checklist` | 例行事项 |
| `groups` | 分组清单 |
| `note` | 说明文字 |

数值字段必须是数字，不能是字符串。写坏的卡片会在大盘上显示成报错块。
